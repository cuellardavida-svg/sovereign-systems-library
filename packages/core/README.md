# @sovereign/core

Shared utilities, types, and base abstractions for the Sovereign Systems Library.

## Exports

- **Types**: `ContentId`, `ISOTimestamp`, `EntityId`, `SovereignMeta`, `VersionedRecord<T>`
- **Result helpers**: `ok()`, `err()`, `isOk()`, `isErr()`, `unwrap()`
- **computeCid(value)**: deterministic SHA-256 content identifier
